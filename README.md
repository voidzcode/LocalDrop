# LocalDrop

A way to share files using a simple Python 3 script.
To use simply clone this repo and run the installer.bat file.
Then open powershell as administrator in the folder that you installed it in, and type in. "python3 main.py" and either "discover" "recieve" or "send"
(e.g. python3 main.py discover)
This repo is completely open-source. As this is a experimental project. It is not encrypted or safe to share important/confidential files. Both devices need to be 
running Windows and on the same network.
